# 四年级数学学习助手 v0.2

这是一个专为家长陪同 9 岁、四年级孩子使用的家庭数学提分与辅导助手。

## v0.2 核心功能亮点

1. **整页多题拍照识别与一键批改**：支持整页作业拍照，AI 自动切分多题、给出分步思路与判断，家长可一键全部归档。
2. **KaTeX 数学公式印刷体排版**：算式、分数、几何角（$\angle 1$）、面积单位（$\text{m}^2$）教材级标准渲染。
3. **🖨️ A4 错题重做练习单导出/打印**：一键生成学生答题留白试卷，支持周末直接打印到纸上重做或导出 PDF，附带家长答案解析。
4. **🎯 AI 举一反三（变式练习）**：针对错题一键生成 3 道同考点同类题，现场作答检验掌握程度。
5. **IndexedDB 大容量存储引擎**：彻底解除 5MB 空间限制，存海量高清照片无压力，旧数据自动平滑迁移。
6. **👧 儿童激励与正反馈**：连续学习打卡日历、攻克错题星星奖励、勋章馆与五彩纸屑庆祝动效。
7. **🔊 温柔女声语音朗读**：一键朗读题目与启发式解题思路，孩子听得更清楚。

## 使用前请知道

- 请家长陪同使用。
- API Key 需要你自己准备，不会写在代码里。
- 作业图片将发送给 AI 服务进行识别，请注意隐私。
- 数据只保存在当前浏览器。清除浏览器缓存可能导致数据丢失。
- AI 结果只是建议，最终以家长确认为准。不确定时会显示“无法判断”或“需家长确认”。

## 如何安装依赖

请先安装 [Node.js](https://nodejs.org/)（建议 20 或更新版本）。安装完成后，打开“终端”或“命令提示符”，进入本项目文件夹：

```bash
cd 女儿学习
npm install
```

如果提示找不到 `npm`，说明 Node.js 还没装好。装好后重新打开终端再试。

## 如何启动

```bash
npm run dev
```

启动成功后，用浏览器打开：

[http://localhost:5188](http://localhost:5188)

看到首页标题「四年级数学学习助手」和三个大按钮，就说明打开对了。

注意：`http://localhost:5173` 可能是电脑上另一个项目（例如专柜游戏），不要用那个地址。

以后如果只想重新打开，还是在这个文件夹里运行 `npm run dev`。

## 如何填写 API Key

1. 打开网页，点右上角或导航里的“设置”。
2. 填写 API Key。
3. 填写模型名称，例如 `gpt-4o-mini`、`gpt-4o`，或其他能看图的多模态模型。
4. 填写接口地址。OpenAI 官方一般是 `https://api.openai.com/v1`。本地用 `npm run dev` 时会自动走代理，避免浏览器跨域。如果你用的是兼容接口，填写服务商给你的地址。打包后的静态网页通常不能直连官方 OpenAI。
5. 点“保存设置”。可用“测试连接”先确认 Key 和地址是否可用。

没有填写 API Key 时：

- 网页不会崩溃
- 首页和上传页会提示先去设置
- 不能开始识别

API Key 只存在你自己的浏览器里，不会出现在项目源代码中。

## 如何使用拍照上传

1. 点首页“拍照 / 上传作业”，或导航里的“拍照/上传”。
2. 手机可点“拍照”，电脑可点“从电脑上传”。
3. 建议 jpg、png。iPhone 相册如果是 HEIC，请先转换成 JPEG。
4. 上传后会显示预览。图片过大时会自动压缩。
5. 点“开始识别”。
6. 识别完成后，家长可以修改题目、学生答案、参考答案、知识点和对错判断。
7. 讲解有两种模式：
   - 引导模式：先给思路、提示、提问，不直接给最终答案
   - 答案模式：显示完整步骤和参考答案
8. 确认后可保存到学习记录；如果是错误、部分正确或需复习，可保存到错题本。

如果当前结果还没保存，重新上传、离开页面或刷新时会询问是否放弃。识别中可点“取消识别”。

如果图片模糊、过暗、题目不完整，识别失败后请重新拍摄。系统不会假装成功。

## 如何保存错题

1. 识别完成后，家长核对学生答案和参考答案。
2. 把判断改成“错误”或“部分正确”，或勾选“需复习”。
3. 错误/部分正确时需要选择错因，例如计算错误、题意没读懂。
4. 点“保存到错题本”。
5. 到“错题本”页可以看到刚保存的题。
6. 点进去可查看图片、题目、讲解、错因，并修改复习状态：未复习、已复习、已掌握。

## 如何导出 / 导入数据

在“设置”页：

- 点“导出 JSON”，会下载学习记录和错题本备份。备份不含 API Key。
- 点“导入 JSON”，确认将替换的条数后，即可恢复基本数据。导入会覆盖当前记录和错题本，请先导出。

也可以先导入项目里的示例文件，熟悉页面：

`examples/sample-backup.json`

## 常见问题

### 打开网页是空白的？

确认已经运行了 `npm install` 和 `npm run dev`，并用浏览器打开终端显示的本地地址。

### 提示没有 API Key？

到设置页填写后再识别。没填写时仍可浏览页面和上传预览。

### 识别失败？

可能原因：

- API Key 无效
- 模型不能看图
- 接口地址写错
- 网络超时
- 图片里没有数学题，或题目不完整

请按页面上的中文提示处理，不要反复提交同一张模糊照片。

### 为什么 AI 说“无法判断”？

这是正常的。第一期要求系统不要编造确定答案。请家长自己核对后修改判断。

### 数据去哪了？

数据在当前浏览器的本地存储里。换电脑、换浏览器、清理缓存，都可能看不到原来的记录。请先导出备份。

如果保存很多带原图的错题，数据主要存在浏览器 IndexedDB 里。换电脑、换浏览器或清理站点数据，仍可能丢失，请先导出备份。

### 能不能不用 OpenAI？

可以。只要服务商提供 OpenAI 兼容的 `/chat/completions` 接口，并且模型能看图，就可以在设置页改接口地址和模型名称。

## 当前版本限制

当前版本是 **v0.2**，已覆盖拍照批改、错题本、打印练习和变式练习。仍不包括：

- 账号登录
- 云端同步
- 多孩子档案
- 语文/英语等其他科目
- 自动判断照片是否模糊
- 本地大模型训练
- 完整教材原题库

讲解会尽量使用四年级上册方法，不主动使用超纲解法。

## 手机上怎么用

和以前一样：推到 GitHub 后，打开这个网页即可（不要用微信内置浏览器）：

https://zonglinxie-cyber.github.io/nuer-xuexi/

只把源码推到 `main` **不会**更新手机网页。需要在电脑上打包并推送到 `gh-pages` 分支后，手机才能看到新版本。

手机上仍要到设置页填写自己的 API Key。官方 OpenAI 在 GitHub 网页上可能被跨域拦住；这时请改用兼容接口（例如能看图的通义/阿里云兼容地址）。错题数据存在**这台手机的浏览器**里，和电脑不共用，换机前请先导出 JSON。
