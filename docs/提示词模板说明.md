# 内置提示词模板说明

版本：v0.1  
代码位置：`src/prompts/mathTutorPrompt.ts`  
调用位置：`src/services/aiService.ts`

## 作用

每次点击“开始识别”时，系统会把下面两类内容发给多模态 AI：

1. 系统提示词：规定角色、年级范围、输出 JSON 字段、儿童语言和安全边界。
2. 用户提示词：要求识别当前作业图片，看不清就明确说明，不要猜测。

## 必须遵守的规则

- 只处理小学数学题。
- 优先识别人教版四年级上册范围内的题目。
- 若无法识别，必须明确说明。
- 若题目不完整，不要猜测缺失数字或条件。
- 输出必须是 JSON，不要 Markdown，不要代码块。
- 不要输出营销内容。
- 不要对孩子使用否定性语言，例如“太笨了”“这么简单都不会”。
- 不确定时，`is_correct` 只能是“无法判断”或“需家长确认”。

## 要求返回的字段

- `recognized_text`
- `confidence_level`
- `question_type`
- `knowledge_point`
- `knowledge_points`
- `textbook_unit`
- `student_answer`
- `ai_answer`
- `is_correct`
- `explanation`
- `step_by_step`
- `hints`
- `known_conditions`
- `asked_question`
- `need_human_check`
- `warning`

## 家长如何理解 AI 结果

AI 结果只是建议。页面上所有关键字段都可以改：

- 题目文本
- 学生答案
- 参考答案
- 知识点
- 对错判断

只有家长点击保存后，学习记录和错题本才会写入浏览器本地数据。
