# 测试用例

第一期至少覆盖下面 3 类作业图片。对应说明和可导入示例数据在 `examples/` 目录。

## 用例 1：一张清晰计算题图片

- 文件：`examples/case-1-clear-calculation.md`
- 目的：验证正常识别、讲解、家长修正、保存学习记录。
- 建议题目：`36 × 24 =`
- 预期：
  1. 能上传并预览图片。
  2. 识别后能看到题目文本、知识点、参考答案和分步讲解。
  3. 家长可切换“引导模式 / 答案模式”。
  4. 家长可修改判断后保存到学习记录。

## 用例 2：一张模糊或不完整图片

- 文件：`examples/case-2-blurry-incomplete.md`
- 目的：验证系统不会假装识别成功。
- 建议情况：字迹过淡、题目被裁切、只拍到半道竖式。
- 预期：
  1. 识别失败，或返回低置信度、`warning`、`无法判断/需家长确认`。
  2. 页面显示友好提示，建议重新拍摄。
  3. 不会把不确定结果当成最终正确答案。
  4. 整个页面不崩溃。

## 用例 3：一张包含学生作答痕迹的图片

- 文件：`examples/case-3-student-answer.md`
- 目的：验证辅助批改和错题本。
- 建议题目：`125 × 32 =`，学生写成 `3750`，正确答案是 `4000`。
- 预期：
  1. 尽量识别出学生答案。
  2. AI 给出初步判断：正确 / 错误 / 部分正确 / 无法判断。
  3. 家长可修改判断和错因。
  4. 保存后能在错题本看到这道题，并能改复习状态。

## 手工操作步骤

1. 按 README 启动网页。
2. 不填 API Key，确认首页和上传页有提示、不会崩溃。
3. 到设置页填写自己的多模态 API Key。
4. 分别用上面 3 类图片走一遍主流程。
5. 导出 JSON，清空浏览器数据后再导入。导入时应出现确认提示；确认后错题本和学习记录能恢复。
6. 设置页可用“测试连接”。识别中可取消。未保存结果时离开拍照页应询问。
